# NJU Generative Software Engineering (2026)

## Descriptions

- Offered by: Nanjing University (Yanyan Jiang)
- Original title: 生成式软件工程 (Generative Software Engineering), Fall 2026
- Language: lectures in Simplified Chinese; my notes in Traditional Chinese
- Period: Nov. 2026 - Present
- Status: 🚧 In progress (lectures 01-12 of 18)

A course on building software with AI coding agents. Instead of treating the model as a code generator, it treats the workspace as state and the agent as a state transition, then asks what specs, architecture, version control, CI, and tests are needed to keep that loop correct and maintainable.

- Wrote notes for lectures 01-12: prompt and context engineering, version control, requirements and architecture, agent-native development, the DeepSeek harness, software evolution, and software quality assurance.
- Upcoming: software analysis tools, deployment and operations, software security, and the open-source ecosystem, plus Lab1 (personal digital assistant) and Lab2 (Deeper Research).
