# NCKU Linux Kernel Internals: fibdrv

## Descriptions

- Offered by: National Cheng Kung University (Jim Huang)
- Programming Languages: C
- Period: Apr. 2022 - Oct. 2022
- Status: ✅ Done

A Linux kernel module that creates the `/dev/fibonacci` device.

- Implemented the Fibonacci function, including formula-based solving and big-number arithmetic.
- Measured performance in both user space and kernel space.
- Optimized the big-number algorithm, improving performance by about 75%.
