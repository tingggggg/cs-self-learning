# Raspberry Pi OS (ARMv8)

## Descriptions

- Offered by: Self-study, following [s-matyukevich/raspberry-pi-os](https://github.com/s-matyukevich/raspberry-pi-os)
- Programming Languages: C / ARMv8 Assembly
- Period: Apr. 2022 - Jul. 2022
- Status: ✅ Done

Built a small operating system for the Raspberry Pi, lesson by lesson:

- **L1 Kernel Initialization**: Mini UART and GPIO setup.
- **L2 Processor Initialization**: ARM exception levels.
- **L3 Interrupt Handling**
- **L4 Process Scheduler**
- **L5 User Processes & System Calls**: moved user processes to EL0 and added system calls.
- **L6 Virtual Memory Management**: isolated processes and the kernel.
