# RISC-V OS (QEMU)

## Descriptions

- Offered by: Self-study, following [plctlab/riscv-operating-system-mooc](https://github.com/plctlab/riscv-operating-system-mooc)
- Programming Languages: C / RISC-V Assembly
- Period: Mar. 2023 - Apr. 2023
- Status: ✅ Done

Built a small RISC-V operating system running on QEMU, step by step: bootstrap and UART, memory management with a buddy system, context switching and multitasking, traps and interrupts, hardware and software timers, preemptive scheduling, locks, and system calls.
