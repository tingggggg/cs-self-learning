# NTHU OS: NachOS

## Descriptions

- Offered by: National Tsing Hua University (OCW)
- Programming Languages: C / C++
- Period: Jan. 2023 - Mar. 2023
- Status: ✅ MP1–MP3 done, 🚧 MP4 in progress

Extended the NachOS 4.0 teaching kernel through the course's machine problems:

- **MP1 System Call**: implemented four I/O system calls.
- **MP2 Multi-Programming**: implemented the page table and reworked memory management so NachOS can run multiple programs at once.
- **MP3 CPU Scheduling**: implemented a multilevel feedback queue scheduler with an aging mechanism.
- **MP4 File System**: work in progress.
